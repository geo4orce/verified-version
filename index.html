vv

Verified Version One strict SemVer triple, always.

Give it a tool. Get strict X.Y.Z.

Missing or unparseable becomes 0.0.0.

POSIX sh. No build.

Install

$ brew install geo4orce/tap/vv

Examples

$ vv git       2.55.0
$ vv node      26.6.0
$ vv nope-xyz  0.0.0
